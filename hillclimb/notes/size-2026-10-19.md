# Binary size after the port of mygo, 2026-10-19

The counter (native UI, no pages, no plugins), ReleaseSmall, Windows
x86_64: 650 KB before the port (nanoui at 8968958), 937 KB after. On Linux
(x86_64, symbols kept to measure them) code and data grew from 454 KB to
685 KB.

What every app of native UI now carries, because every one uses it:

| what | about |
|---|---|
| Direct3D 11 renderer, its bytecode (`d3d11.cso`) and effect passes (Windows) | 60 KB |
| OpenGL renderer through libepoxy/EGL (Linux) | 30 KB |
| Text shaping engines: DirectWrite (Windows), HarfBuzz/FreeType/fontconfig (Linux), bidi (UAX #9), myzig's own TrueType kept as the fallback | 45 KB |
| Accessibility: UI Automation (Windows), AT-SPI over D-Bus (Linux), the semantic tree | 25 KB |
| Transforms, gradients, blur and backdrop effects in the CPU renderer, motion in paint | 25 KB |
| Right to left (mirroring), grids in layout, Tab focus traversal | 6 KB |

What was linked though the counter doesn't use it, and how it was cut:

- The embedded GLSL, HLSL and Metal sources carried their comments, and
  Windows apps carried `d3d11.hlsl` itself to check `d3d11.cso` against
  at run time: sources are now minified at compile time
  (`src/ui/shader_min.zig`), the bytecode's hash is compared at compile
  time, and only Debug builds keep the source to compile a stale shader
  (−20 KB).
- The generator of the TypeScript client (sorting services, writing
  declarations) was reached from `App.run`'s `--myzig-generate`: it is now
  reached through a function `bind` and `registerEvent` register, so apps
  that bind nothing write the runtime's part only (−9 KB on Linux).

Left, small: the handlers of signals and network status (`quit_on_signal`
is on by default, about 1.5 KB), flyout placement (1 KB), and a page's
`destroy` reached from a window's teardown (2 KB on Linux).

Measured with `nm --size-sort -S` on Linux builds of the counter (before:
a worktree of 8968958; after: this tree), summed by module.
