# Ngôn ngữ

`myzig.i18n` hiện thông báo của app bằng ngôn ngữ của người dùng, trong native UI lẫn trong trang. Nó theo package `i18n` của mygo.

Thông báo nằm trong các catalog, mỗi ngôn ngữ một tệp, được nhúng lúc build và kiểm tra lúc biên dịch. Những lỗi sau là lỗi biên dịch, không phải bất ngờ trên production:

- một key mà catalog thiếu;
- một đối số mà lời gọi bỏ sót hoặc truyền sai kiểu;
- một bản dịch có key hoặc đối số mà bản gốc không có;
- một thông báo không parse được.

```zig
const i18n = myzig.i18n;

const L = i18n.Catalog(.{
    .source = "en",
    .files = .{
        .en = @embedFile("locales/en.json"),
        .de = @embedFile("locales/de.json"),
    },
});

fn view(s: *App, c: *ui.Context) void {
    ui.heading(c, L.text(.title));
    ui.text(c, L.t(c, .filesSelected, .{ .count = s.selected.len }), .{});
}
```

App không dùng nó thì không bị link gì vào. Dữ liệu ngày tháng chỉ vào app có định dạng ngày.

<a id="catalogs"></a>

## Catalog

Catalog là một tệp ARB cho mỗi ngôn ngữ: JSON, như của Flutter và Chrome. Tệp được đặt tên theo tag BCP 47 chuẩn của ngôn ngữ: `en.json`, `de.json`, `zh-Hant.json`, `pt-BR.json`.

```json
{
  "@@locale": "en",
  "title": "Notes",
  "@title": { "description": "The window's title." },
  "greeting": "Hello, {name}!",
  "@greeting": { "placeholders": { "name": { "type": "String", "example": "Ada" } } },
  "filesSelected": "{count, plural, =0 {No files selected} one {# file selected} other {# files selected}}",
  "@filesSelected": { "placeholders": { "count": { "type": "int" } } },
  "price": "Total: {amount, number, ::.00}",
  "@price": { "placeholders": { "amount": { "type": "double" } } },
  "due": "Due {day, date, medium}"
}
```

- Mỗi key đặt tên cho một thông báo: một chữ cái, rồi chữ cái, chữ số và `_`.
- Key bắt đầu bằng `@` mô tả thông báo của key đứng sau nó.
- `@@locale`, nếu có, phải là ngôn ngữ của tệp.
- Key dạng `<namespace>.<key>` thay thông báo của một thư viện (`myzig.undo`, [bên dưới](#myzig-s-own-strings)).
- Catalog gốc có mọi key. Đó là tùy chọn `source`, mặc định là tiếng Anh. Bản dịch có thể thiếu key, khi đó sẽ fallback.

`.files` là một struct mỗi ngôn ngữ một trường, như trên, hoặc một slice các cặp: `.{ "de", @embedFile("locales/de.json") }`. `.pseudo = true` thêm các pseudo locale ([bên dưới](#trying-a-language)).

<a id="argument-types"></a>

### Kiểu đối số

`type` của một placeholder là một trong:

- `String`;
- `int`, `double` hoặc `num` (một số);
- `DateTime` (một `i18n.DateTime`);
- `Object`.

Đối số không khai báo kiểu thì lấy kiểu từ cách thông báo dùng nó. Được `plural` đếm thì là số; được `date` ghi thì là ngày. Lời gọi truyền đối số sai kiểu sẽ không biên dịch được:

```zig
L.text(.titel)                                  // no member 'titel' in Key
L.text(.greeting)                               // greeting has arguments
try L.printIn(w, "de", .greeting, .{})          // needs the argument name
try L.printIn(w, "de", .filesSelected, .{ .count = "3" })   // takes an integer
```

<a id="messages"></a>

## Thông báo

Thông báo theo cú pháp ICU MessageFormat:

| Cú pháp | Nó ghi ra |
|---|---|
| `{name}` | một đối số |
| `{n, plural, =0 {...} one {# file} other {# files}}` | một trường hợp theo quy tắc số nhiều của CLDR cho ngôn ngữ của thông báo; `#` là con số |
| `{n, selectordinal, one {#st} two {#nd} few {#rd} other {#th}}` | một trường hợp theo quy tắc số thứ tự |
| `{gender, select, female {She} male {He} other {They}}` | một trường hợp theo một chuỗi |
| `{amount, number}`, `{amount, number, ::.00}`, `{p, number, percent}`, `integer`, `::group-off` | một số theo locale, với một style hoặc skeleton |
| `{day, date, short\|medium\|long\|full}`, `{t, time, short}` | ngày hoặc giờ theo locale |
| `'{name}'`, `''` | chữ trong dấu nháy, một dấu nháy đơn |

- Các trường hợp số nhiều theo quy tắc CLDR cho mọi ngôn ngữ CLDR có: `few` và `many` của tiếng Nga, sáu trường hợp của tiếng Ả Rập, v.v.
- `i18n.cardinalCategory` và `i18n.ordinalCategory` cho biết trường hợp. `i18n.cldr_version` là phiên bản CLDR.
- `i18n.exact("1.50")` truyền một số thập phân giữ nguyên các chữ số lẻ. Loại số nhiều của nó là loại của số có hai chữ số lẻ.

<a id="in-zig"></a>

## Trong Zig

| Lời gọi | Việc nó làm |
|---|---|
| `L.text(.key)` | thông báo của một key không có đối số, bằng ngôn ngữ app đang hiện |
| `L.textIn(locale, .key)` | như trên, bằng `locale` |
| `L.t(c, .key, args)` | thông báo cho native UI, trong bộ nhớ của frame của `c` |
| `L.print(w, .key, args)`, `L.printIn(w, locale, .key, args)` | ghi nó vào một `std.Io.Writer` |
| `L.alloc(gpa, .key, args)`, `L.allocIn(gpa, locale, .key, args)` | cấp phát nó |
| `L.bufPrintIn(buf, locale, .key, args)` | ghi nó vào một buffer |

`L.languages` liệt kê các ngôn ngữ của catalog, ngôn ngữ gốc đứng đầu. `L.missing` liệt kê các key mỗi ngôn ngữ còn thiếu, cho một test muốn mọi bản dịch đầy đủ:

```zig
test "every translation is whole" {
    inline for (L.missing, 0..) |m, i| {
        if (m.len > 0) std.debug.print("{s} lacks {s}\n", .{ L.languages[i], m[0] });
        try std.testing.expectEqual(@as(usize, 0), m.len);
    }
}
```

`i18n.formatMessage(w, locale, "message", args)` ghi một thông báo viết thẳng trong code, không nằm trong catalog. Nó được parse lúc biên dịch.

<a id="the-language-the-app-shows"></a>

## Ngôn ngữ app hiện

Cả app hiện một ngôn ngữ, `i18n.locale()`: là "en" cho tới khi app đặt ngôn ngữ khác. App đặt nó bằng `i18n.setLocale`, trên main thread. App chọn ngôn ngữ trong catalog hợp với người dùng nhất:

```zig
const langs = try myzig.system.languages(gpa);
defer myzig.system.freeList(gpa, langs);
i18n.setLocale(i18n.matchedLanguage(langs, L.languages));
```

`i18n.locale()` là ngôn ngữ app hiện, không phải của người dùng. App tự dịch chữ của mình, không dùng catalog, sẽ nhận `"en"` từ nó cho tới khi gọi `setLocale`. Ngôn ngữ của người dùng thì đọc từ `myzig.system.languages`.

`i18n.match(preferred, supported)` trả về chỉ số của ngôn ngữ khớp nhất, hoặc null. Nó thử lần lượt:

1. ngôn ngữ và vùng: `en-GB` cho `en-AU`, vì cả hai thuộc `en-001`;
2. chỉ ngôn ngữ;
3. vùng thường gặp của ngôn ngữ đó;
4. bất kỳ vùng nào khác.

Ngôn ngữ người dùng ưu tiên hơn sẽ thắng một ngôn ngữ khớp sát hơn nhưng ít được ưu tiên: `fr` cho `fr-CA` thắng `de` cho `de`. `matchedLanguage` fallback về ngôn ngữ được hỗ trợ đầu tiên, tức ngôn ngữ gốc của app.

Một thông báo được tìm theo ngôn ngữ đang hiện, rồi các fallback theo parent locale của CLDR, rồi ngôn ngữ gốc. `i18n.parent` và `i18n.chain` cho các fallback: `en-AU`, `en-001`, `en`. Các thread khác tự chỉ định locale (`printIn`, `textIn`).

<details><summary><code>App.Locale()</code> của mygo trước 0.5</summary>

`App.Locale()` của mygo đổi sang cách này từ bản 0.5. Trước đó nó trả về ngôn ngữ ưu tiên đầu tiên của người dùng, bất kể app được viết bằng ngôn ngữ nào.

</details>

<a id="when-the-language-changes"></a>

### Khi ngôn ngữ thay đổi

- `setLocale` tăng một bộ đếm thế hệ, `i18n.localeGeneration()`. View nào giữ chữ thì so sánh nó để biết ngôn ngữ đã đổi.
- Native UI dựng mọi frame từ state. View lấy thông báo bằng `L.text` và `L.t` sẽ hiện ngôn ngữ mới ở frame kế tiếp.
- Sau `setLocale`, yêu cầu frame đó bằng `redraw` của cửa sổ.

<a id="right-to-left"></a>

### Phải sang trái

- `i18n.direction(tag)` cho biết một ngôn ngữ có viết từ phải sang trái không: tiếng Ả Rập, Do Thái, Ba Tư, Urdu, theo chữ viết của chúng.
- `ui.direction.fromLocale(c, i18n.locale())` dàn cửa sổ native UI theo hướng đó (xem [Phải sang trái](ui/right-to-left.md)).

<a id="regional-formats"></a>

### Định dạng theo vùng

| Lời gọi | |
|---|---|
| `myzig.system.locale(gpa)` | locale của người dùng ("en-US") |
| `myzig.system.region(gpa)` | vùng của người dùng ("US") |
| `i18n.regionFor(locale)` | một `i18n.Region`: locale, `first_weekday` (0 là Chủ nhật tới 6 là Thứ bảy) và chu kỳ giờ (12 hoặc 24) |
| `i18n.firstWeekday(locale)`, `i18n.hourCycle(locale)` | như trên, từng cái một; extension `-u-fw` và `-u-hc` của tag cũng cho biết |
| `i18n.autonym(locale)` | tên một ngôn ngữ bằng chính nó ("Deutsch", "简体中文"), cho menu chọn ngôn ngữ |

<a id="numbers-and-dates"></a>

## Số và ngày tháng

Số và ngày tháng được ghi như ICU và Intl ghi. Dữ liệu lấy từ CLDR, cho 62 locale và những locale fallback về chúng: dấu phân cách, cách nhóm, chữ số, tên tháng và thứ, pattern theo style và skeleton, 12 hoặc 24 giờ.

```zig
var buf: [64]u8 = undefined;
_ = try i18n.bufFormatNumber(&buf, "de", 1234.5, .{});                  // "1.234,5"
_ = try i18n.bufFormatNumber(&buf, "en", 0.25, .{ .percent = true });   // "25%"
_ = try i18n.bufFormatNumber(&buf, "en", 1.5, .{ .min_fraction = 2 });  // "1.50"

const t = i18n.DateTime.utc(2026, 1, 5, 13, 7, 9);
_ = try i18n.bufFormatDate(&buf, "en", t, .{ .date = .medium });        // "Jan 5, 2026"
_ = try i18n.bufFormatDate(&buf, "en", t, .{ .time = .short });         // "1:07 PM"
_ = try i18n.bufFormatDate(&buf, "en", t, .{ .skeleton = "MMMd" });     // "Jan 5"
```

| `i18n.NumberOptions` | Mặc định | |
|---|---|---|
| `percent` | `false` | nhân 100, kèm dấu phần trăm của locale |
| `integer` | `false` | làm tròn thành số nguyên |
| `min_fraction`, `max_fraction` | 0, `null` | số chữ số lẻ; `null` là mặc định của style |
| `min_integer` | 0 | thêm số 0 vào trước phần nguyên |
| `grouping` | `true` | dấu phân cách hàng nghìn |
| `half_even` | `false` | làm tròn nửa về số chẵn, như MessageFormat của ICU, thay vì ra xa số 0 như Intl |

| `i18n.DateOptions` | |
|---|---|
| `date`, `time` | style: `.short`, `.medium`, `.long`, `.full` |
| `skeleton` | một skeleton của CLDR ("yMMMd", "MMMd", "Ed", "jm", ... trong `i18n.date.skeletons`) |
| `hour_cycle` | 12 hoặc 24, để theo cài đặt của người dùng |

- Một `i18n.DateTime` là số giây kể từ 1970 theo UTC, kèm `offset_minutes` tùy chọn của múi giờ.
- `formatNumber` và `formatDate` ghi vào một `std.Io.Writer`.
- `i18n.months(locale, width, stand_alone)`, `i18n.weekdays(...)` và `i18n.dayPeriods(locale, width)` cho các tên, theo cách lịch cần. `i18n.Width` là `.wide`, `.abbreviated`, `.short` hoặc `.narrow`.

<a id="myzig-s-own-strings"></a>

## Chuỗi của chính myzig

`myzig.l10n` chứa những gì control và menu của myzig nói: "Undo", "Next month", "Quit Notes", những cái tên mà công nghệ hỗ trợ đọc. Chúng hiện bằng ngôn ngữ app đang hiện.

- Có sẵn tiếng Anh, tiếng Trung giản thể, phồn thể và tiếng Nhật: `src/l10n/en.json`, `zh-Hans.json`, `zh-Hant.json`, `ja.json`, lấy từ catalog của mygo.
- Một bản dịch chỉ được biên dịch vào app có ngôn ngữ đó. App không mang bản dịch nào mà nó không hiện.
- App có các ngôn ngữ trong catalog của nó, mà tệp gốc khai báo, cùng những ngôn ngữ nó tự liệt kê:

```zig
// in main.zig
pub const myzig_catalog = L;              // an app with zh-TW.json gets zh-Hant
pub const myzig_languages = .{"zh-Hans"}; // and these, besides
```

App thay chuỗi của myzig, hoặc dịch chúng sang các ngôn ngữ khác của nó, bằng các key `myzig.<key>` trong catalog:

```json
{
  "myzig.undo": "Rückgängig",
  "myzig.menuQuitApp": "{app} beenden"
}
```

Một chuỗi được tìm theo thứ tự sau, trong ngôn ngữ của app, các fallback của nó và ngôn ngữ gốc của app:

1. trong các chuỗi app thay thế;
2. trong bản dịch của myzig;
3. bằng tiếng Anh.

Lấy một chuỗi chỉ tốn một lần tra và không cấp phát gì: `myzig.l10n.text(.undo)`, `textIn(locale, key)`, `printIn(w, locale, key, args)`.

<a id="trying-a-language"></a>

## Thử một ngôn ngữ

Với `.pseudo = true`, catalog có thêm hai pseudo locale. Chúng được tạo từ thông báo của bản gốc, để xem layout của giao diện trước khi dịch:

- `en-XA` (`i18n.pseudo_accents`) thêm dấu vào các chữ cái, làm chữ dài hơn khoảng 40% và bọc trong ngoặc: "[Šéļéçţ ƒîļéš one two]". Nó giúp tìm chuỗi không nằm trong catalog, bị cắt, hoặc bị ghép từ nhiều mảnh.
- `ar-XB` (`i18n.pseudo_bidi`) hiện mỗi từ từ phải sang trái, và dàn app từ phải sang trái. Nó giúp tìm chỗ không lật chiều.

```zig
i18n.setLocale(i18n.pseudo_accents);
```

`i18n.isPseudo(tag)` phân biệt chúng. Chúng dùng quy tắc số nhiều của tiếng Anh.

<a id="in-pages"></a>

## Trong trang

Thông báo của catalog tới trang qua client được sinh ra (`myzig.js`, `myzig.d.ts`; xem [Bindings](bindings.md)). Đăng ký catalog giống như app đăng ký event:

```zig
try app.registerEvent(i18n.Page(L)); // adds `messages` to the client
```

```ts
import { messages, messagesIn, languages, onLocaleChange } from "./myzig.js";

heading.textContent = messages.filesSelected(3);
messagesIn("de").greeting("Ada"); // "Hallo, Ada!"
onLocaleChange((locale) => render());
```

- Mỗi key có một hàm có kiểu. Nó tạo thông báo bằng Intl của trình duyệt, với cùng thông báo, trường hợp và fallback như trong Zig.
- Thông báo nằm sẵn trong client, nên lần vẽ đầu tiên đã đúng ngôn ngữ.
- `messages` dùng ngôn ngữ của trang: `window.myzig.locale` nếu có, nếu không thì `lang` của document, nếu không nữa thì `navigator.language`.
- `onLocaleChange` lắng nghe event `myzig:locale` của trang. myzig chưa tự gửi event này. App đổi ngôn ngữ của trang thì tự gửi event đó, hoặc trang tự render lại.

<a id="package-reference"></a>

## Tham khảo package

`src/i18n/i18n.zig` export:

- thông báo: `Catalog`, `Message`, `formatMessage`, `bufFormatMessage`, `Exact`, `exact`;
- ngôn ngữ đang hiện: `locale`, `setLocale`, `localeGeneration`;
- so khớp: `match`, `matchOne`, `matchedLanguage`, `fallbacks`, `Fallbacks`;
- tag: `Tag`, `normalize`, `parent`, `chain`, `base`, `maximize`, `likelyScript`, `likelyRegion`, `Direction`, `direction`, `isPseudo`, `pseudo_accents`, `pseudo_bidi`;
- số nhiều: `Plural`, `Operands`, `Categories`, `cardinalCategory`, `ordinalCategory`, `cardinalCategories`, `ordinalCategories`;
- số: `NumberOptions`, `formatNumber`, `bufFormatNumber`;
- ngày tháng: `date`, `DateTime`, `DateOptions`, `Style`, `Width`, `formatDate`, `bufFormatDate`, `months`, `weekdays`, `dayPeriods`;
- vùng: `firstWeekday`, `hourCycle`, `autonym`, `Region`, `regionFor`;
- trang: `Page`;
- `message`, bộ parser, cho các công cụ đọc thông báo lúc biên dịch.

Các bảng quy tắc số nhiều, số và ngày tháng được sinh từ CLDR bằng các script trong `src/i18n/gen/`. Chúng được test với kết quả của chính ICU (`src/i18n/tests_*`).
